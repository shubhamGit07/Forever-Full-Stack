# FOREVER – Full Stack E-Commerce Website

A modern MERN Stack E-Commerce platform with user authentication, product management, shopping cart, order processing, and admin dashboard.

## 🚀 Live Demo
https://forever-frontend-ruby-kappa.vercel.app

## 🛠 Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- Axios
- React Router DOM

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas
- Mongoose

### Authentication
- JWT Authentication
- bcrypt

### Cloud Storage
- Cloudinary

## ✨ Features

- User Registration & Login
- JWT Authentication
- Product Listing & Filtering
- Shopping Cart Management
- Order Placement
- Admin Dashboard
- Product Management
- Responsive Design
- Cloudinary Image Upload

## ⚙️ Installation

### Clone Repository

```bash
git clone <your-repository-url>
cd forever
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Backend Setup

```bash
cd backend
npm install
npm start
```
## 🔐 Environment Variables

Create a `.env` file inside the backend folder:

```env
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_SECRET_KEY=your_secret_key
```
